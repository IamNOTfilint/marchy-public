# Marchy

Marchy is an independent, rebranded development of the Omarchy desktop experience. It is built on Arch Linux and the Hyprland compositor. It is created by [IamNOTfilint](https://github.com/IamNOTfilint).

## The idea

**Okonomi for taste. Okimari for safety.**

- **Okonomi** means "as you like it." Marchy's setup asks what you want and does not pre-select your apps, browser, office suite, AI tools, or desktop style.
- **Okimari** means a fixed course. For people who want a set menu, Marchy offers presets: Nami (minimal), Jo (dev), Tokujo (full), and Hardened.
- **Safety floor** is not a taste choice: firewall, full-disk encryption, signed packages, no passwordless sudo, and no telemetry.

## What this repo is

This public repository holds documentation, the website, and upstream credits. The OS source lives in a private repository.

## Status
