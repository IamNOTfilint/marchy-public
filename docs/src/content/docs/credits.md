# Credits

Marchy is an independent project. It builds on the work of these projects. This repository links to their official project pages; it does not vendor their source code.

| Project | Link | Role |
|---|---|---|
| Omarchy | https://github.com/omacom/omarchy | Baseline desktop experience (MIT) |
| Arch Linux | https://archlinux.org | Base distribution |
| Hyprland | https://github.com/hyprwm/Hyprland | Compositor |
| Quickshell | https://github.com/quickshell-mirror/quickshell | Shell toolkit |
| Linux kernel | https://github.com/torvalds/linux | Kernel |
| systemd | https://github.com/systemd/systemd | Init and user space |

Each project retains its own license. See the upstream repository for exact license terms and source code.

Marchy is not affiliated with or endorsed by any of these projects.
