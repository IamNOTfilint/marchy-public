# Marchy — public home

Documentation, website, and upstream credits for Marchy.

Marchy is an independent, rebranded development of the Omarchy desktop experience. It is not affiliated with or endorsed by the Omarchy project.

## Repositories

- **OS source:** private (`IamNOTfilint/marchy`)
- **Public home:** this repository — docs, website, credits
- **Docs site:** https://IamNOTfilint.github.io/marchy-public/

## Philosophy

**Okonomi for taste. Okimari for safety.**

- **Okonomi:** choose your own apps, desktop, and workflow. No pre-selected boxes.
- **Okimari:** fixed safe courses for people who want a set menu.
- **Safety floor:** firewall, full-disk encryption, signed packages, no passwordless sudo, no telemetry.
